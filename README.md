# Loan Application Assessment & Approval System

An end-to-end AI-powered loan assessment and approval workflow developed using UiPath.

[▶️ Watch the Project Demo](https://drive.google.com/drive/folders/1i1JfAXgUq_hiXaNIFd5qR0eWJ2k0zWVA?usp=sharing)

## Project Overview

This project automates the process of assessing a loan application, evaluating risk, obtaining manager approval, generating a decision email, and sending the email automatically.

## Workflow

Loan Application
→ Application Analysis Agent
→ Risk Assessment Agent
→ Manager Approval
→ Email Generation Agent
→ RPA Email Automation

## Technologies Used

- UiPath Agentic AI
- UiPath Maestro
- Context Grounding
- UiPath Apps
- Robotic Process Automation (RPA)
- Excel-based Risk Context
- Google Workspace

## Key Features

- AI-based loan application analysis
- Context-grounded risk assessment
- Risk scoring and risk-level classification
- Manager approval/rejection through UiPath Action App
- Automated decision email generation
- Automated email delivery using RPA
- End-to-end orchestration using UiPath Maestro

## Risk Assessment

The system evaluates the application using an Excel-based dataset containing:

- Risk criteria
- Risk scoring rules
- Loan purpose rules
- Risk combinations
- Decision actions

The system returns:

- Risk Level
- Risk Score
- Recommended Action
- Assessment Summary
